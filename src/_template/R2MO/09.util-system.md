使用 `r2-sys-integrate` 技能将所有已开发页面模块整合成完整系统。基于各模块的 `menu.yaml` 建立菜单驱动的路由体系。

**关键输入**:
- 所有模块的 `menu.yaml` (菜单定义和 URI 路由映射)
- 所有页面的生成代码 (来自 r2-dev-page)
- 项目文件: `src/app.rs`, `src/pages/mod.rs`, `src/components/layout.rs`, `src/context/mod.rs`, `src/models/mod.rs`

**核心工作**:
1. 解析所有 menu.yaml，建立菜单→URI 映射
2. 注册所有模块到 src/pages/mod.rs
3. 为每个模块创建 mod.rs，定义 Route 对应 menu.yaml 的 URI
4. 更新 src/app.rs 实现完整路由树 (Leptos Router)
5. 创建/更新 src/components/layout.rs 实现菜单导航
6. 聚合全局 Context (MenuContext + 其他 modules contexts)
7. 定义 MenuItem 类型和路由参数类型

**铁律**:
- menu.yaml 是唯一的路由真实来源，所有 Route 的 path 必须与 menu.yaml 的 URI 完全一致
- 保留已有代码结构，不移动不重命名文件
- Leptos Router 规范，Context API 管理状态，避免 prop drilling
- 类型安全的路由，无魔法字符串

**输出**: src/pages/{module}/mod.rs
