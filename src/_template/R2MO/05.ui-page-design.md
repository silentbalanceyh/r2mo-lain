--- BEGIN
使用 `r2-dev-html` 技能对当前模块进行页面设计，每个页面生成一份带页面ID的静态原型：`{PAGE-ID}.html` 输出到对应的页面目录下，设计时参考 `.r2mo/design/spec.md` 中的设计规范。

输入：
- 静态页不需要模版页面，菜单可以参考模块目录中的 `menu.yaml` 配置。
- `.r2mo/design/spec.md` 中存储了系统页面的设计规范。
- 模块目录：`requirement.module.md` 中包含了模块的详细需求。

输出：
- 严格遵循 rules ( `*.mdc` ) 规范和 skills 中的规范
- 输出内容精简，让AI可以更容易理解
- 页面目录下输出：{PAGE-ID}.html 的页面原型文件

模块：ID,NAME,PATH
