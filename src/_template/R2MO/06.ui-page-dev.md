--- BEGIN
使用 `r2-dev-page` 技能根据页面需求规范生成前端代码。生成内容包括：页面组件、状态管理、API 客户端、类型定义、常量、样式和测试。

**关键输入**:
- `requirement.page.md` (第 3/4/6 节: 数据模型、API 列表、表单字段)
- `page.yaml` (6 个生命周期配置)
- `.r2mo/api/marker.md` (字段属性标记)
- `.r2mo/design/spec.md` (设计规范)

**必须遵守**:
1. 前端 HTTP 客户端仅调用，不实现后端 API
2. API 路径严格来自 requirement.page.md，不创建不修改
3. 表单/列表字段严格遵循 marker.md 的属性标记
4. 6 个生命周期实现: init(权限/数据/字典), query(验证/API), action(CRUD), validate(规则), event(交互), cleanup(清理)
5. 技术栈严格按 project.md，无假设

**输出**: src/pages/{module}/{page}/ 下的 7 种文件

模块：ID,NAME,PATH
