使用 `r2-dev-layout` 技能开发应用主布局模板（`src/components/layout.rs`）。主布局提供全局导航、菜单、页面容器框架，承载所有业务模块页面。

**关键输入**:
- 各模块的 `menu.yaml` (菜单定义、导航结构、权限)
- AppContext (登录用户信息、权限、系统配置)
- `.r2mo/design/spec.md` (设计规范: 配色、字体、响应式)
- 页面组件 (来自已集成的各模块)

**核心结构**:
- 顶部导航栏 (系统标题、用户信息、登出按钮)
- 左侧菜单栏 (从 menu.yaml 动态渲染、可收起)
- 主内容区 (Leptos Router Outlet，显示当前页面)
- 响应式设计 (桌面、平板、手机)

**关键功能**:
1. 动态菜单渲染 (从 menu.yaml 获取菜单项、支持二级菜单)
2. 菜单高亮 (根据当前路由高亮对应菜单项)
3. 菜单收起/展开 (侧边栏宽度切换，图标显示隐藏)
4. 用户信息显示 (从 AppContext 获取用户名、头像、权限)
5. 登出功能 (清空认证信息、返回登录页)
6. 响应式导航 (移动设备菜单抽屉)

**必须遵守**:
1. AppLayout 包装除登录页外的所有页面 (在 src/app.rs 中配置)
2. 菜单项来自对应模块的 menu.yaml，URI 必须与路由一致
3. 当前路由通过 use_location() 获取，高亮对应菜单项
4. 用户信息、权限从 AppContext 取，不硬编码
5. 左侧菜单宽度固定 (展开时 w-64, 收起时 w-20)，响应式时可隐藏菜单栏
6. 设计遵循 spec.md (颜色、字体、间距)

**输出**: src/components/layout.rs (AppLayout 组件及菜单相关子组件)
