# BUT-ai-cmd 安装后命令不可见与 debug 报告闭环

## Observed Bug

- `mxt ai-cmd` 在新环境或 Windows 场景中可能提示安装完成，但宿主未真正识别 `/mxt:*` 或 `$mxt-*` 命令。
- `mxt:debug` / `$mxt-debug` 只输出诊断结论，不能沉淀为 `goon-xxx.md`，后续无法直接用整改模式闭环。

## Root Cause

- Claude Code 插件发现依赖 `~/.claude/plugins/known_marketplaces.json` 与 `~/.claude/plugins/installed_plugins.json`，原实现只复制文件并写 `settings.json`，在 CLI 未可用、刷新失败或新环境初始化不足时会出现“文件存在但 `claude plugin list` 不识别”的状态。
- DEBUG 命令模板没有强制解析三位编号，也没有规范化 `<GOON_PATH>` 和 `DEBUG Report` 写回格式。

## Fix

- `mxt ai-cmd` 安装 Claude 平台时同步写入 Claude host plugin state，卸载时同步清理；临时新 HOME 下 `claude plugin list` 可识别 `mxt@mxt-skills` 为 enabled。
- `mxt-debug` 三平台模板和 Codex skill 增加三位编号解析、`<GOON_PATH>` 写回校验、`DEBUG Report` 模板和整改项输出，供 `$mxt-goon <编号>` / `/mxt:goon <编号>` 直接整改。
- `npm test` 改为显式 `node src/index.test.js`，避免 Unix 可执行位和 Windows shell 差异导致测试脚本不可运行。
